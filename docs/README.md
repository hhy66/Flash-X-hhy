# Flash-X 文档中心

本目录是项目的**唯一文档来源**。根目录只保留 `README.md`（面向使用者）和 `CLAUDE.md`（面向 AI 助手的工作指南）。

## 阅读顺序

第一次接手，按这个顺序读：

1. [`../README.md`](../README.md) — 产品是什么、三个核心能力
2. [`ARCHITECTURE.md`](ARCHITECTURE.md) — 代码怎么分层、扫描算法怎么跑
3. [`FEATURES.md`](FEATURES.md) — 每个功能落在哪个文件、有没有测试
4. [`ISSUES.md`](ISSUES.md) — **先看这里**，当前有哪些红灯
5. [`DEVELOPMENT.md`](DEVELOPMENT.md) — 怎么把项目跑起来
6. [`TODO.md`](TODO.md) / [`PROGRESS.md`](PROGRESS.md) — 接下来做什么

## 维护约定

1. **文档跟着代码走。** 改动对外可见的行为（命令、文件格式、UI 菜单）时，同一提交内更新对应文档。
2. **状态必须可验证。** `FEATURES.md` 的"验证方式"列要么指向具体测试名，要么写"手工：<步骤>"，不要写"应该没问题"。
3. **问题先记录再修。** 发现的缺陷先进 `ISSUES.md`（哪怕当场就修），保留"发现 → 证据 → 修复"的链路。
4. **不要在文档里复制代码。** 引用 `路径:行号` 或符号名即可，避免双份真相。
5. **`research/` 不进版本库**（见 `.gitignore`）。任何要长期留存的内容必须迁到本目录。
